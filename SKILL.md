# TalkToReview Marketer

## Overview
This skill leverages the "AI Pull Quotes" feature of TalkToReview.com to create high-converting marketing materials directly from customer testimonials.

## Features
- **Social Post Generator**: Turns short pull quotes into Instagram captions, Tweets, and LinkedIn posts.
- **Ad Copywriter**: Creates variations of ad copy based on real customer words.
- **Email Booster**: Integrates customer voices into abandoned cart or review request emails.

## Usage
Use this skill when you need to:
- Create a social media calendar from voice reviews.
- Generate headlines for a landing page using customer quotes.
- Draft a newsletter featuring recent "Wall of Love" entries.
