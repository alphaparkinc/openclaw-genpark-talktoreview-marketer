# GenPark TalkToReview Marketer

![TalkToReview Marketer](./assets/icon.png)

## Description
A specialized AI skill for **GenPark** that transforms [TalkToReview.com](https://talktoreview.com/) pull quotes into high-converting marketing copy.

## Features
- **One-Click Socials**: Generate Twitter, LinkedIn, and Instagram posts from a single voice review.
- **Ad Creative Helper**: Turn customer testimonials into persuasive ad headlines and body text.
- **Social Proof Integration**: Dynamic copy generation for landing page "Wall of Love" sections.

## Installation
Configure your TalkToReview account and link your social media automation tools via GenPark.
